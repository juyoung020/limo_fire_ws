# HEADER · FARE 와 우리 탐사 RL 의 차이

2026-11-11 에 두 논문 본문을 끝까지 읽고 정리했다. 논문 쪽 수치는 모두 논문 본문·표에서 옮긴 것이고,
우리 쪽은 `train/explore` 직접 제어 모드(v10 기준) 값이다.

- HEADER: Cao et al., arXiv 2510.15679 (2025-10)
- FARE: Liao et al., arXiv 2601.14681 (2026-01). 같은 연구실(NUS Sartoretti)이 HEADER 위에 얹은 후속작

## 한 줄 요약

저쪽은 **"다음에 갈 지점"을 1~2.5 Hz 로 고르고**, 우리는 **바퀴 속도를 10 Hz 로 직접 낸다.**
보상도 정반대다. 저쪽은 GT 지도를 아는 전문가(또는 LLM)가 고른 지점과의 거리 하나만 쓰고,
우리는 가중치가 붙은 항 여러 개를 더한다.

## 1. HEADER 와 우리

| 항목 | HEADER | 우리(직접 제어) |
|---|---|---|
| 행동 | 현재 노드의 이웃 노드(최대 25 개) 중 하나를 다음 경유점으로 선택(이산) | v, ω 연속 속도 명령 |
| 결정 주기 | 1~2.5 Hz | 10 Hz |
| 입력 | 그래프 노드마다 값 5 개: 위치 x·y, 유틸리티(보이는 프론티어 수), 지역·전역 길잡이(0/1) | 근거리 지도 6×64×64, 원거리 지도 7×32×32, 깊이 1×40×64, 1 차원 1304 |
| 원시 센서 | 신경망에 안 들어간다(지도 → 그래프로 가공한 뒤 입력) | 라이다·깊이가 그대로 들어간다 |
| 신경망 | 어텐션 인코더 6 층 + 포인터 디코더, 특징 128 차원 | CNN + MLP 512-256-128, 약 279 만 파라미터 |
| 입력 크기 | 가변(노드 수가 달라져도 된다) | 고정 |
| 먼 곳 정보 | 고전 알고리즘이 계산해 0/1 신호로 넣어 준다: Leiden 커뮤니티 분할 → 전역 그래프 → TSP 경로 | 원거리 지도(0.8 m 칸)를 CNN 이 직접 해석 |
| 보상 | 항 1 개. 전문가 경유점과 고른 경유점의 거리, 범위 [−1, 0], 가중치 없음 | 가중치가 있는 항 여러 개(`mdp/rewards.h`) |
| 학습 알고리즘 | SAC, 환경 16 개 병렬, 재생 버퍼 10 만, 배치 128, 할인율 0.95 | PPO 계열, 환경 2048 개 GPU 병렬 |
| 학습 지도 | 무작위 던전 4000 장(250×250 칸, 칸 0.4 m) | HSSD 등 실제 집 메시 |
| 학습 시간 | RTX 4080 에서 약 16 시간 | v10 은 8 만 반복 |
| 에피소드 | 최대 200 결정 | T_ref 기반 시간 제한 |
| 끝 조건 | 프론티어가 0 이 되면 끝 | 끝 선언 행동(2026-11-11 끄기로 함) |
| 충돌 | 문제에 없다(그래프 간선이 처음부터 충돌 없는 직선) | 벽·사람 충돌 벌점, 근접 벌점 |
| 움직이는 사람 | 다루지 않는다(Octomap 광선 갱신이 일부 지워 주는 정도) | 걷는 사람이 시뮬에 있다 |
| 로봇 동역학 | 다루지 않는다(경유점까지 가는 일은 하위 스택 몫) | 바퀴 미끄러짐·속도 한계 포함 |
| 센서 | 전방위 3D 라이다(시뮬 16 채널, 실기 Ouster OS0-32). 범위 시뮬 20 m, 실기 8 m | 2D 라이다 + 전방 깊이 카메라 |
| 위치 추정 | Fast-LIO2 로 정확하다고 가정 | 실기 오도메트리 오차를 겪는다 |
| 규모 | 130 m × 100 m ~ 340 m × 340 m | 집·사무실 크기 |
| 속도 | 시뮬 2 m/s, 실기 1 m/s | 최대 1 m/s |
| 실기 | Agilex Scout-mini, i7-12700H 미니 PC, GPU 불필요 | LIMO Pro |
| 지표 | 이동 거리, 완료 시간(makespan), 결정당 계산 시간, 탐사 부피-시간 곡선. 10 회 평균 ± 표준편차 | 성공률, 성공 시간, 충돌률, 덮음(거리·T_90/T_99·곡선은 추가 예정) |
| 누적 이동 거리 입력 | 없다 | 넣기로 함(2026-11-11) |

HEADER 가 스스로 밝힌 한계: 다층 건물 불가, 계단 같은 음의 장애물은 손으로 막음,
시야가 좁은 센서와 로봇 방향(heading)은 향후 과제.

경유점까지 실제로 어떻게 주행하는지(하위 제어기)는 논문에 설명이 없다.

### HEADER 의 전문가 보상

1. 학습 중 매 결정마다 GT 지도를 아는 계획기가 "남은 곳을 다 덮는 가장 짧은 경로"를 계산한다.
   시점을 확률적으로 뽑아 프론티어를 모두 덮게 한 뒤 TSP 로 순서를 정하고, 여러 번 반복해 가장 짧은 것을 고른다.
2. 그 경로의 첫 경유점 w* 와 정책이 고른 경유점 w 의 거리 d 로 보상을 준다:
   `r = −(e^(d/2dn) − 1)/(e − 1)`, 범위 [−1, 0].
3. 가중치가 없고, 정보가 안 보이는 긴 되돌아가기 구간에서도 매 걸음 신호가 나온다.

절제 실험(같은 100 개 시험 지도, 완료까지 이동 거리):

| 방법 | 거리 | 최적과의 차 |
|---|---|---|
| 최적(GT 를 아는 전문가) | 502 m | 0 % |
| HEADER | 529 m | 5.3 % |
| 전역 그래프 없는 HEADER | 552 m | 10.0 % |
| TARE Local(전문가와 같은 알고리즘, GT 없음) | 558 m | 11.1 % |
| ARiADNE + 지역 길잡이 | 579 m | 15.3 % |
| ARiADNE | 606 m | 20.7 % |
| 보상 조형으로 학습한 HEADER | 627 m | 25.0 % |
| 행동 복제로 학습한 HEADER | 661 m | 31.7 % |

여기서 보상 조형은 "새로 본 면적 보상 + 이동 거리 벌점 + 완료 보상"이다.

## 2. FARE 가 HEADER 에 더한 것

구조는 "느린 생각(LLM, 전역) + 빠른 생각(RL, 지역)" 두 층이다. 빠른 쪽은 HEADER 의 신경망 그대로다.

| 항목 | HEADER | FARE |
|---|---|---|
| 전역 경로 | 전역 노드 위 TSP(OR-Tools) | LLM(Qwen3-14B)이 전역 그래프·전략 글·에피소드 기억을 보고 경로를 낸다 |
| 사람이 주는 정보 | 없다 | 환경을 한 줄로 설명해 줘야 한다(예: "좁은 통로가 있는 창고") |
| 전략 | 없다 | LLM 이 설명을 정해진 틀(공간·장애물·난점)로 분석하고, 전략 표 4 축(공간·효율·안전·과제)을 채운다 |
| 전역 그래프 | 커뮤니티 전부 | 모듈성 기여가 큰 상위 k 개 커뮤니티만 남긴다 |
| 노드 입력 | x, y, 유틸리티, 지역·전역 길잡이 | x, y, 유틸리티, 길잡이 1 개(전역 경로 위인지) |
| 보상 | GT 전문가 경유점과의 거리 | LLM 전역 경로의 다음 경유점과의 거리: `r = −(e^d − 1)/(e − 1)`, d 는 4·√2·노드 간격으로 나눈 값 |
| 실기 컴퓨터 | i7 미니 PC | Jetson AGX Orin(LLM 을 로봇 위에서 돌림) |
| 실기 장소 | 건물 200 m × 130 m, 정원, 캠퍼스 300 m × 230 m | 건물 200 m × 130 m 한 곳 |

Gazebo 결과(10 회 평균, 이동 거리 / 완료 시간):

| 방법 | 실내 | 숲 | 창고 |
|---|---|---|---|
| DSVP | 1511 m / 931 s | 2058 m / 1083 s | 869 m / 582 s |
| TARE | 1209 m / 658 s | 1363 m / 711 s | 652 m / 366 s |
| ARiADNE | 1053 m / 610 s | 1320 m / 790 s | 521 m / 362 s |
| HEADER | 1030 m / 576 s | 1230 m / 725 s | 492 m / 286 s |
| FARE | 1048 m / 590 s | 1090 m / 680 s | 441 m / 252 s |

- 창고·숲에서는 HEADER 보다 10~11 % 짧다. 실내는 HEADER 보다 오히려 길다(1030 → 1048 m).
  논문은 실내가 "작고 전역 구조가 뚜렷하지 않아서"라고 적었다.
- 이득의 근거로 든 행동: 탐사한 영역의 가장자리·구석을 미루지 않고 먼저 끝내 되돌아가기를 줄인다.

FARE 논문에 없는 것:

- LLM 한 번 추론에 걸리는 시간과 호출 주기. "안정적으로 돌았다"는 말만 있다.
- 절제 실험. LLM, 가지치기, 새 보상 가운데 무엇이 이득을 냈는지 알 수 없다.
- 학습 설정(알고리즘, 지도, 시간). HEADER 를 따른다고만 읽힌다.
- LLM 이 틀린 경로를 낼 때의 처리.

### FARE 와 우리

HEADER 와의 차이(위 표)는 그대로 적용된다. 여기에 더해:

| 항목 | FARE | 우리 |
|---|---|---|
| 사전 정보 | 환경 설명 글이 필요하다 | 없다. 처음 보는 곳에 그대로 들어간다 |
| 로봇 위 계산 | 14B LLM + 신경망 | 279 만 파라미터 신경망 하나 |
| 상위 판단 | LLM 이 전역 경로를 낸다 | 없다(직접 제어). 계층형 모드는 상위가 목표를 고른다 |
| 보상의 기준 | LLM 경로를 따르는 정도 | 탐사량·시간·충돌 등 환경에서 직접 잰 값 |

## 3. 우리에게 의미 있는 점

1. **보상 설계가 정반대다.** 같은 신경망을 보상 조형으로 학습하면 627 m, 전문가 보상이면 529 m 였다.
   우리 보상은 전자 계열이다.
2. **행동 복제만 쓰면 더 나쁘다(661 m).** 계층형 → 직접 제어를 행동 복제로 시작하는 안에 참고할 수치다.
3. **가장 가까운 프론티어만 가리키면 성능이 떨어진다.** HEADER 는 길잡이를 가장 가까운 유틸리티 노드에만 주면
   "가까운 것만 쫓게 된다"고 적었다. 우리 `approach` 항(가장 가까운 프론티어까지 거리 감소)이 같은 구조다.
4. **실내 크기에서는 전역 계층의 이득이 작을 수 있다.** FARE 는 실내에서 이득이 없었고,
   HEADER 도 실내·숲에서는 ARiADNE 와 비슷했다.
5. **저쪽이 안 다루는 영역이 우리 쪽이다.** 좁은 시야, 로봇 방향, 충돌, 사람, 10 Hz 반응은 두 논문 모두 다루지 않는다.
   대신 "얼마나 짧게 도는가"는 저쪽 방식이 유리한 구조다.
6. **FARE 방식은 우리 로봇에 그대로 못 올린다.** 14B LLM 을 AGX Orin 에서 돌린다. 환경 설명 글도 사람이 써 줘야 한다.

## 4. 정한 것 (2026-11-11)

직접 제어를 접고 계층형으로 돌아가 HEADER 구조를 따르기로 했다. 주행·충돌·사람 대응은 우리 하위 주행(경로 계획 + 추종기)을 그대로 쓴다.

| 순서 | 내용 | 상태 |
|---|---|---|
| 1 | 행동을 이웃 노드 선택으로, 입력을 노드 그래프(위치·유틸리티·길잡이)로, 상위 정책에서 원시 센서 제외 | 진행 |
| 1 | 어텐션 인코더 6 층 + 포인터 신경망(PPO 는 유지) | 진행 |
| 2 | GT 전문가 경유점 보상, 최적 대비 차 지표 | 다음 |
| 3 | 커뮤니티 전역 그래프, 무작위 학습 지도 | 1·2 결과를 보고 |

- 노드 간격은 0.8 m(잠정)로 잡았다. 지도 창 25.6 m 가 노드 32 × 32 자리에 다 들어가서 전역 그래프 없이도 전체를 본다.
- HEADER 코드는 공개되지 않았다(지형 분할 모듈만 공개). 논문과 전작 공개 코드
  (github.com/marmotlab/large-scale-DRL-exploration)를 참고해 C++/CUDA 로 새로 짠다.
