# autocrawler — AutoCrawler 로 탐지 학습 이미지 늘리기

`../external/AutoCrawler`(Apache-2.0, 고치지 않음)를 그대로 돌리는 실행 스크립트와 클래스별 검색어.
공개 데이터에 부족한 **한국식** 비상구 표지·소화기·소화전함, 촛불, 실내 계단을 보탠다.

```bash
./run.sh                       # keywords/*.txt 전부
./run.sh candle stairs         # 일부만
LIMIT=400 THREADS=4 ./run.sh   # 키워드당 최대 장수·동시 브라우저 수
```

- 처음 돌리면 `.venv/`(uv, Python 3.12)에 selenium 등을 깐다. Chrome 필요(chromedriver 는 자동).
- 결과: `../../data/raw/autocrawler/<클래스>/<검색어>/naver_0000.jpg …`, 로그 `<클래스>.log` 에 **원본 URL** 이 남는다(출처 기록).
- 이미 끝난 검색어(`naver_done`)는 건너뛴다. 다시 받으려면 그 폴더를 지운다.

## 목표 (늘림)

| 클래스 | 우리 클래스 번호 | 검색어 | 이전 목표 | 목표 |
|---|---|---|---|---|
| `exit_sign` | 3 exit_sign | 비상구 표지·피난구 유도등·통로 유도등 등 13 개 | 800 | **2,000** |
| `fire_extinguisher` | 2 fire_extinguisher | 소화기·분말 소화기·소화전함·옥내소화전 등 14 개 | 800 | **2,000** |
| `candle` | 0 fire | 촛불·양초 불꽃·티라이트 등 12 개 | 600 | **1,500** |
| `stairs` | 6 stairs | 실내·학교·비상 계단, 계단실 등 13 개 | 800 | **2,000** |

키워드당 250 장 × 12~14 개 ≈ 클래스당 3,000~3,500 장을 받고, 중복·그림(클립아트)·관계없는 사진을 걸러 목표를 채운다.

## 알아 둘 것

- **Google 은 쓰지 않는다**(`--no-google`). 헤드리스 Chrome 에 CAPTCHA 가 떠서 0 장이 나온다. Naver 만 쓴다.
- `--full`(원본 해상도): Naver 썸네일은 340 px 안팎이라 작다. 원본은 500~900 px.
- 검색 결과 사진은 대부분 저작권이 있다. 학습에만 쓰고 공개 저장소·발표 자료에 다시 싣지 않는다(`../external/README.md` 주의 참고).
- 받은 사진에는 라벨이 없다. 라벨 달기 전 중복 제거·걸러내기가 필요하다.
