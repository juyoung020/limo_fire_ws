# detect — YOLO 탐지

불·연기·소화기·비상구 표지·사람·문·계단을 찾는 YOLO 탐지기. 순찰(소방 시설 지도)과 화재 대응(불 크기 판단)에 쓴다.

| 폴더 | 내용 | 상태 |
|---|---|---|
| `trainer/` | C++/CUDA 학습기. ObjectSAM(`~/ObjectSAM/src`, YOLOv8s-seg 1 클래스, 4,253 줄)에서 가져와 클래스 수를 설정으로, 마스크 없이 상자만 학습하게 바꾼다 | 할 일 |
| `tools/` | 데이터셋 → 학습 형식 변환(Rust) | 할 일 |
| `data/` | 이미지·라벨 (git 제외) | 할 일 |

| 2 | fire_extinguisher | 소방 시설 지도 |
