## 빌드

```bash
cmake -S train/explore/ppo -B <빌드> -DCMAKE_CUDA_COMPILER=/usr/local/cuda-13.0/bin/nvcc   # RTX 3060 = sm_86 기본
cmake --build <빌드> -j8
<빌드>/gradcheck && <빌드>/gradcheck --negative && <빌드>/gradcheck --full
<빌드>/toy_train --envs 256 --iters 150 --seed 1 --eval-every 25
<빌드>/toy_train --envs 256 --iters 4 --check-determinism
<빌드>/toy_train --envs 256 --iters 8 --check-resume --ckpt <경로>
<빌드>/bench --envs 2048
<빌드>/cnn_check && <빌드>/cnn_bench && <빌드>/tail_check
```

## 러너가 부를 API (`ppo.h`, 모든 포인터는 GPU)

```cpp
xppo::PPO ppo(xppo::PPOConfig{/*num_envs=*/2048, ...}, xnet::explore_spec(), seed);
void act(const uint8_t* obs_img /*[N][IMG_SIZE]*/, const float* obs_1d /*[N][POLICY_1D]*/,
         const float* priv /*[N][PRIV], nullptr=0*/, float* actions /*[N][4]*/);   // 학습: 샘플·기록·정규화 갱신
void store(const float* reward /*[N]*/, const int* done /*[N]: 0 진행, 1 종료(선언·충돌), 3 끊김*/);
UpdateStats update(const uint8_t* obs_img, const float* obs_1d, const float* priv); // steps_per_env 번 act/store 뒤, 다음 관측으로
void act_inference(const uint8_t* obs_img, const float* obs_1d, float* actions, int n = -1); // 평균 행동, 선언 = p > 0.5
void save(const std::string& path) const;  void load(const std::string& path);      // 반복 사이에서만
int iteration() const;  float learning_rate() const;  xnet::ActorCritic& ac();
```

- `actions`: 연속 3 은 샘플 원값(자르지 않음, 환경이 [−1,1] 로 자르고 한도를 곱함), 선언은 0/1.
- `UpdateStats`: surrogate·value·entropy(가우시안)·kl·lr·grad_norm(자르기 전)·mean_value·mean_return.
- 체크포인트: 머리(형식·`sizeof(real)`) → 층 이름·크기 목록(구조가 다르면 불러오기 거부) → 가중치·Adam m·v·걸음 수 → 정규화 μ·σ²·개수 → 반복 수·학습률·act 호출 수·씨앗.
  `.tmp` 에 쓰고 이름 바꾸기. 같은 체크포인트에서 이어 학습하면 끊지 않은 학습과 비트 단위로 같다(아래 검증 4).

## σ 범위 (2026-11-05, 브랜치 sigma-cap)

**문제**: 정책 σ 는 상태 무관 변수(`log_std`)이고 환경은 정규 단위 행동을 [−1, 1] 로 자른다(sim `env.h apply_action` 의 `clip1` 뒤 한도 v 1 m/s·vy 1 m/s·ω 3.14 rad/s 를 곱함).
잘리니 σ 를 키워도 대리 손실 쪽 손해가 거의 없고 엔트로피 보너스(−c·Σ log σ)는 늘 σ 를 키운다 → `runs/explore_v3`(main 41ed9a5, 씨앗 1) `train/std` 1.0 → 2.1(반복 300) → 7(700) → 23(1100) → 99.6(1541),
`explore_v2` 끝 7.9. 행동이 거의 늘 한계에서 잘려 좌우로 튐(재생에서 ω 부호가 걸음마다 ~30 % 뒤집힘).

**고침**: (1) `PPOConfig::std_min = 0.05, std_max = 1` — 매 Adam 걸음 뒤와 체크포인트 불러오기 뒤에 log σ 변수를 [ln 0.05, 0] 로 투영. (2) `entropy_coef` 0.005 → 0.001.
- σ_max = 1: 정책 출력이 정규 단위라 세 성분 모두 행동 한계 반폭 = 1 (= 초기 σ, rsl_rl `init_noise_std = 1.0`). 물리로는 v 1 m/s(뒤는 0.3)·vy 1 m/s·ω 3.14 rad/s.
- σ_min = 0.05: **잠정**. 원래 하한 없음. 반폭의 5 %(ω 0.16 rad/s) — σ 가 작을수록 log π 가 1/σ 로 민감해져 비율이 튀고 탐사가 사라진다. 평가·배포는 평균 행동이라 영향 없음.
- 방식 고르기 — 공개 구현:
  - rsl_rl v2.3.1 `modules/actor_critic.py`: σ 제한 없음(`Normal(mean, std)` 그대로).
  - rsl_rl main `modules/distribution.py` `GaussianDistribution(std_range=(1e-6, 1e6), std_type="log")`: 정방향에서 `log_std_param.clamp(*log_std_range)` 로 분포를 만듦
    (https://github.com/leggedrobotics/rsl_rl/blob/main/rsl_rl/modules/distribution.py).
  - SB3 SAC `sac/policies.py`: `LOG_STD_MIN = -20, LOG_STD_MAX = 2`, `th.clamp(log_std, LOG_STD_MIN, LOG_STD_MAX)` 정방향
    (https://github.com/DLR-RM/stable-baselines3/blob/master/stable_baselines3/sac/policies.py).
  - 정방향 clamp 는 범위 밖에서 기울기가 0 — 우리처럼 log σ 가 상태 무관 변수 하나면 상한을 넘은 변수는 엔트로피·대리 손실 기울기가 모두 0 이라 그 자리에 멈추고,
    Adam 관성으로 더 밖으로 밀려도 돌아올 기울기가 없다(σ 를 줄이고 싶어져도 못 줄임). 그래서 **걸음 뒤 투영(사영 경사 하강)**을 골랐다:
    변수가 늘 범위 안이라 손실은 clamp 없는 매끈한 함수이고 기울기는 그대로 정확하며, 샘플(`k_sample`)·log π·엔트로피·KL(`k_loss`)·체크포인트·재생이 모두 같은 변수를 읽는다.
    `onnx_export` 는 체크포인트를 직접 읽으므로 같은 범위로 묶는다(옛 체크포인트용 — `explore_v3` 의 σ 99.5 → 내보낸 log σ 0, 0, 0).
- 엔트로피 0.005 → 0.001: 상한에 붙은 동안 엔트로피 기울기는 투영에 지워지지만, 0.005 는 σ 를 상한으로 밀어 정책이 σ 를 줄일 여지를 막는다(legged_gym 0.01 은 행동을 자르지 않는 관절 목표용).

## 평균 행동 경계 (2026-11-05 밤, `PPOConfig::bound_coef` · `train --bound-coef`)

**문제**: 정책 평균 μ 는 자르지 않는 선형 출력이고 환경은 [−1, 1] 로 자른다(sim `env.h apply_action` `clip1`). μ 가 경계 밖으로 나가면
표본이 모두 잘려 같은 행동이 되므로 대리 손실 기울기의 기댓값이 0 — μ 는 잡음만 받으며 떠내려가고 그 성분(특히 감속)을 다시 못 배운다.
게다가 KL 은 μ 의 움직임을 그대로 세므로 잘린 영역에서 떠내려가는 것도 KL 적응 학습률을 깎는다.

**증거** (`runs/explore_v7`, 시험 맵 결정적 평가, 맵마다 64 판, `train --eval-ckpt`):

| 체크포인트 | σ (v, vy, ω) | 평균 μ_v | 걸음 중 μ_v > 1 | μ_v > 1.5 | bookstore 성공·충돌 /64 | small-house 성공·충돌 /64 |

## 계층형 — 가린 범주 분포 (2026-11-08, `ACSpec::n_slots > 0`, `train --hier`)

행동 = 후보 슬롯 하나 (mdp/README "계층형"). actor MLP 출력은 상태 임베딩(64), 슬롯 머리(`network/slot_head.cuh`)가 슬롯마다 같은 MLP 로 로짓,
가림 = 날 1D 관측의 후보 "있음" 칸(정규화 전). 빈 슬롯은 log-sum-exp 에서 빠져 확률이 정확히 0, 있는 슬롯이 없으면 0 번·log π 0·기울기 0.
log π·엔트로피(샘플마다 −Σ p log p, 계수 `entropy_coef`)·KL(옛 ‖ 새) 모두 있는 슬롯만. σ·선언 로짓·평균 행동 경계 손실 없음.
샘플 = Philox(연속 판과 같은 씨앗·부분열) 균등 하나로 누적 확률, 결정 행동 = 있는 슬롯 중 로짓 최대. 환경 행동은 `[슬롯, 0, 0, 0]`.
머리 상수 편향은 두지 않는다(모든 로짓에 같은 값 — 기울기가 늘 0 이라 기울기 검사가 처음에 잡음).

## 슬롯 로짓 공통 성분 (2026-11-10, `PPOConfig::slot_cm_coef` · `train --slot-cm-coef`)

**증상.** explore_h2(`--hier`, 2048 환경, 목표 KL 0.01, lr 상한 1e-3)가 반복 2889 에서 발산: 기울기 노름 ~1e2 → 4e4(2890) → 1e9(3790),
학습률은 한 반복(미니배치 20 번 × ÷1.5) 만에 하한 1e-5 에 닿아 끝까지 거기, KL 0.05 → 14. 끝 체크포인트의 슬롯 로짓 8 개가 모두 ≈ 1.68e9 라
차이가 float 해상도(≈ 128) 아래 — 결정 행동은 늘 0 번 슬롯, 엔트로피 0(아래 "log-softmax").

**원인 — 되돌리는 힘이 없는 방향.** 가린 범주 분포는 있는 칸 로짓에 같은 값을 더해도 같다. 그래서 대리·엔트로피 기울기 G_k 는 샘플마다 있는 칸 합이
정확히 0 이고, 로짓 공통 성분 l̄ 은 손실에 아무 힘도 받지 않는다. 슬롯 머리 `logit_k = w2·ELU(W1_z z + b1 + W1_f f_k)` 에서 정책은 슬롯 차이를 키우려고
은닉 단위를 기울기 1 인 양수(선형) 구역으로 민다(ELU 음수 구역은 기울기 exp(a) < 1). 선형 구역 단위의 슬롯 무관 몫 w2_h·(W1_z z + b1)_h 는
그대로 l̄ 에 쌓이고, 그 단위로 오는 기울기는 w2_h·Σ_k G_k = 0 이라 줄어들 길이 없다. Adam 은 기울기 크기와 무관하게 lr 만큼 걸어
(2850 체크포인트 `head.b1` 의 √v ≈ 6e-8 인데 0.15 → 0.25 로 움직임) 이 방향으로 계속 떠내려간다.
l̄ 이 커지면 (1) 로짓 하나가 1e5 여도 차이(표준편차 ~1.5)를 담을 자리가 float 에서 줄고, (2) 임베딩 z 와 가중치 곱이 커서 작은 걸음에도 단위가
구역을 넘나들어 정책이 튀며, (3) 롤아웃과 갱신 정방향(묶음 크기가 다른 GEMM)의 반올림 차이가 KL 로 나온다 — 걸음 전 KL(`train/kl0`)이 l̄ 과 같이 큰다.
적응 학습률은 KL 이 학습률 때문이라 가정하므로 (3) 이 커지면 하한까지 내려가 갇힌다.

후보별 확인: 출력 상수 편향은 처음부터 없다(slot_head.cuh). 가림은 큰 음수 상수가 아니라 log-sum-exp 에서 칸을 빼는 방식이라 무관.
log-softmax 는 최댓값을 뺐지만 `lz = mx + log Σ` 를 먼저 더해 |l| ≳ 1e7 이면 log Σ 가 반올림에 먹혀 Σ p = V 가 되었다(엔트로피 0 표시의 원인 — 고침, 발산 원인은 아님).
엔트로피 기울기 p_k(log p_k + H) 도 있는 칸 합 0 이라 공통 성분과 무관. 가치 손실은 발산 내내 6~7 로 정상. 전체 기울기 노름 자르기는 actor 기울기 1e5 일 때
critic 기울기도 1e-5 배로 줄여 critic 을 사실상 멈췄지만 결과이지 원인이 아니다 — Adam v 합에서 critic 몫이 반복 1500 0.85 → 2850 0.24 → 3600 0.00,
actor 쪽(인코더·MLP·머리) 몫이 0.00 → 0.75 → 1.00.

**고침.** 손실에 c·mean_i h(l̄_i), h = Huber(δ 10: |l̄| ≤ 10 이면 l̄², 넘으면 2δ|l̄| − δ²), c = 1e-3. 로짓 기울기 2c·clamp(l̄, ±δ)/V 는 있는 칸 모두 같아
정책(확률)엔 1 차로 영향이 없고 공통 성분만 0 으로 당긴다(게이지 고정). 꼴은 MoE 라우터 z-loss — 소프트맥스 로짓이 기울기 없이 커져 반정밀도에서
불안정해지는 것을 c·(log Σ exp)² 로 막음(ST-MoE, Zoph 2022, c = 1e-3; PaLM, Chowdhery 2022, 1e-4). z-loss 는 log Σ 를 당겨 확률에도 조금 손대지만
평균 l̄ 은 순수 공통 방향이라 그걸 골랐다. Huber 상한은 이미 l̄ 이 1e5 인 체크포인트를 이어 받을 때 이 항이 기울기를 독차지하지 않게.
정방향(로짓·샘플·결정 행동)은 그대로라 옛 체크포인트의 행동이 바뀌지 않고 체크포인트 형식도 그대로(형식 3) — 옛 `--hier` 체크포인트는 그대로 불러진다.
"로짓 중심 빼기"(softmax 앞에서 l̄ 빼기)는 쓰지 않았다: 분포가 이미 l̄ 에 무관해 빼도 기울기가 0 인 것은 같고, 정밀도는 l_k 를 더할 때 이미 잃는다.
참고로 SB3-contrib `MaskableCategorical`·CleanRL(gym-μRTS) 의 invalid action masking(Huang & Ontañón 2020)은 가린 칸 로짓을 −1e8 로 바꾼다 — 우리는 칸을 빼는 쪽이라 같은 분포.

**안전장치 — 학습률 하한 갇힘.** 적응 학습률 규칙(rsl_rl 꼴, 미니배치마다 ÷1.5)은 KL 이 학습률 탓이라 가정해, 한 반복(20 걸음) 안에 1e-3 → 1e-5 로 갈 수 있고
KL 이 학습률과 무관하면(공통 성분 1e7 에서 로짓 반올림 ~1 이 표준편차 0.8 보다 큼) 다시 오를 길이 없다. 그래서 `train` 은 lr 이 하한이고 반복 KL 이 목표의 2 배를 넘는
반복이 10 번 이어지면 사건을 남기고 멈춘다(종료 코드 4, `model_latest` 를 덮기 전). 학습률을 되살리는 규칙은 넣지 않았다 — 갇힌 망은 이미 정밀도를 잃어 학습률을 올려도 못 돌아온다. 진단으로 `progress.jsonl` 에 `train/kl0`·`train/logit_cm`(|l̄| 샘플 평균)·`train/logit_spread`
(있는 칸 표준편차)·`train/logit_absmax` 를 남긴다.

어디에 시간이 드나(nsys, 환경 1024): 합성곱·MLP GEMM ≈ 50 %, 편향+ELU·ELU 역방향 ≈ 25 %, u8→float 재배치 ≈ 11 % — 대부분 메모리 대역 한계(fp32 활성값; 가까운 지도 첫 층 출력 16×32×32 가 가장 큼).
더 빠르게 하려면: 편향+ELU 를 GEMM 뒤에 합친 커널, 활성값 fp16(정합성 검사 다시), 첫 층 4×4 stride 4. 이번에는 안 함.
