### 움직이며 — GPU 환경 전체를 실물 녹화로 다시 돌리기 (replay_check)

실물 `/cmd_vel` 을 50 Hz 그대로 GPU 환경 커널에 넣고, 그 녹화의 Cartographer 확률 지도 등고선으로 세운 장면(map2scene)에서 실물 시작 자세부터 돌린다. 라이다는 같은 시각 실물 Cartographer 자세에서 쏴 실물 `/scan` 과 빔마다 비교, 빠짐은 지도에서 확실한 칸(≥ 80 %)을 맞힌 빔만.
빠짐 모델을 다 끄면 실물만 맞힌 빔 0.3 % — **형상·자세 정렬·광선 추적은 실물과 맞다**.

## IMU — 가속도 x·y·z, 자이로 x·y, roll·pitch (2026-11-04)

`ros2 run limo_fire_sim motion_export <녹화> <csv>` (IMU 원값 열: 그 시각 직전 `/imu` 메시지 그대로 — 보간하면 잡음이 줄어서) →
`tools/imu_check [--fit]` (녹화 목록은 [calibration.yaml](calibration.yaml) `imu:`). 시뮬 모델은 [include/imu.h](../include/imu.h), 값은 [sensor_model.yaml](../config/sensor_model.yaml) `imu`,
학습 환경이 물리 걸음마다 `EnvState::imu.out` (ax, ay, az, gx, gy, roll, pitch) 에 만든다. 확인 도구는 실물 녹화의 몸통 움직임(바퀴 v, 자이로 ω, 바퀴 v 미분)을
같은 함수에 넣어 시뮬 IMU 를 만들고 같은 통계로 비교한다(잡음 모델만 비교 — 구동은 motion_check 가 따로 확인).

**roll·pitch 방향**: 드라이버 소스는 바이트 필드 이름이 뒤바뀌어 있지만 `setRPY(pitch, roll, yaw)` 로 다시 뒤바꿔 넣어 나오는 쿼터니언은 REP-103 그대로다.
8 녹화 정지 평균에서 쿼터니언 roll = atan2(ay, az), pitch = −atan2(ax, az) 가 1 mrad 안(예 spot1: −0.0040 / −0.0044, −0.0019 / −0.0020), 0.5 s 자이로 x 적분은
쿼터니언 roll 변화와 상관 0.22~0.62, 쿼터니언 pitch 변화와는 −0.09~0.26 (평평한 바닥이라 기울기 변화가 작아 상관은 약함 — 정지 중력 비교가 주 근거). 시뮬도 REP-103 (roll = x 축, pitch = y 축).

| 항목 | 실측 (맞춤 녹화) | 시뮬 |
|---|---|---|
| 정지 가속도 크기 | 10.034 m/s² (9.80 보다 2.4 % 큼) | `g` |
| 바닥 기울기 | 자리마다 roll·pitch 0.0006~0.0044 rad, RMS 0.0025 — 정지 ax·ay 평균이 이 기울기의 중력 몫과 같음 | 판마다 N(0, 0.0025) |
| 가속 → 가속도 | ax = 1.05·몸통 가속, ay = 1.06·v·ω (원심) | `k` |
| 가속 → 기울기 | pitch −0.0003 rad per m/s², roll −0.010 rad per m/s² (작음) | `tilt` |
| 잡음 정지 σ | 가속도 0.09 · 0.03 · 0.03 m/s², 자이로 x·y 0.0015 · 0.0021 rad/s, roll·pitch 0.0015 · 0.0027 rad | `noise` s0 |
| 주행 진동 | 바퀴가 돌기만 해도 가속도 σ 0.3~0.9 m/s², 빠르면 1~1.3 (z 가 가장 큼), 자이로 x·y 0.015 → 0.04 rad/s. 분산이 속도에 대략 선형 | 움직이면 σ² = q1 + qv·\|v\| + qw·\|ω\| |
| 스펙트럼 (0.1 s 자기상관) | 가속도·자이로 ≈ 0 (진동은 10 Hz 위 — 정책 주기에선 흰 잡음), roll 0.98 · pitch 0.92 (자세 추정 필터가 느림) | AR(1) 상관 시간 roll 6.2 s · pitch 1.1 s, 나머지 흰 잡음 |

확인 (spot3 · cmd1 · drive1, 맞춤과 다른 녹화, 허용 차이는 확인 전에 정함: 잔차 σ ±30 %, 0.1 s 자기상관 ±0.2, 원값 σ ±30 %): **35 항목 중 31 통과**.
미달: ay 정지 σ (시뮬 0.033 / 실물 0.024), az 느림 σ (0.61 / 0.39), gx 느림 σ (0.020 / 0.015), pitch 정지 σ (0.0028 / 0.0019) — 넷 다 시뮬이 더 시끄러운 쪽.

## 지도 속도 — Cartographer 지도 자세 미분 (2026-11-04, 학습 환경엔 아직 안 넣음)
