# 실물 녹화 목록 (`~/limo_bags`)

시뮬 = 현실을 맞추고 확인하는 데이터. 녹화 파일은 커서 저장소에 넣지 않고 로봇의 `~/limo_bags/<이름>` 에 둔다(백업은 따로). 녹화는 늘 같은 토픽 묶음으로:

```bash
ros2 launch limo_fire_bringup robot.launch.xml [base:=false]      # base:=false 는 센서만 (충전 중·세워 두고)
ros2 launch limo_fire_bringup record.launch.xml name:=MMDD_상황 [depth:=false]
```

무엇을 왜 담는지는 [data_plan.md](data_plan.md). 녹화마다 아래 표에 한 줄 적는다(배터리 전압·바닥·줄자 값 포함). 쓰는 도구: `scan_stats_bag`(정지 라이다 통계), `bag_export` → `replay_check`(같은 자세로 시뮬을 돌려 실물과 빔마다 비교).
