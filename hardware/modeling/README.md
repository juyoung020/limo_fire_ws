# 3D 모델링 원본

LIMO 에 다는 출력물의 원본 모델링 폴더. 개인 저장소 `3d-modeling` 에 있던 것을 11/14 에 옮겨 왔다. 폴더 이름과 구조는 스크립트가 서로를 상대 경로로 찾기 때문에 그대로 두었다.

| 폴더 | 내용 |
|---|---|
| `LIMO센서/` | 열화상·레이더 팔, 초음파 막대, 전장 판·덮개. `설계.md` 가 기준. 출력 파일은 `print/`, 조립 검사용은 `stl/` |
| `탁구공발사대/` | 탁구공 발사대 설계·출력 파일·시뮬(`sim_*.py`, `v4b/`, `v5/`)·서보 시험 펌웨어 |
| `불꽃과녁/` | 공에 맞으면 넘어가는 불꽃 과녁 |
| `lib/` | 나사산·필렛·두께·조립 그림 공용 코드 |
| `docs/` | 출력 전 조립 검증 절차 |

## 쓰는 법

- 모델은 Python(manifold3d, trimesh)으로 만든다: `python build_arm.py` → `stl/`, `print/` 갱신, `python check_arm.py` → 검사.
- 조립 그림은 Blender 를 창 없이 돌린다: `blender -b --python lib/render_asm.py -- out.png "a.stl|r,g,b" ...`

## 여기에 넣지 않은 것

남이 만든 자료라 다시 올리지 않았다. 일부 검사 스크립트는 이 파일들이 있어야 돈다.

- `ref/` 폴더들: LIMO 몸체·바퀴 메시(AgileX URDF), 서보 STEP, 참고한 공개 모델. 출처는 각 설계 문서에 적혀 있다.
- `datasheets/`: 센서 데이터시트 PDF.
- 조립 그림 중 이전 버전, 슬라이스 결과물.
