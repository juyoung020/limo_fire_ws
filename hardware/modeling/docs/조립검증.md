## 1. 조립 좌표 맞추기
- 짝부품의 기준(축 구멍 중심, 나사 구멍, 바닥면)을 메시 단면에서 잰다. `trimesh.section`으로 자른 면의 고리마다 범위를 보면 된다.
- 내 부품을 그 기준으로 옮기고 돌린다. 이 변환은 함수 하나로 두고, 검사와 렌더에 똑같이 쓴다.
- 예(불꽃 과녁)
  - 과녁 축은 과녁 좌표 (y -32, z -0.5)이고, 받침 구멍 중심은 (0, 0, 26)이다.
  - 과녁 y는 받침 z(위)가 된다.
  - 변환: `T = t.translate([0, 32, 0.5]).rotate([90, 0, 0])`, 각도 a에서 `T.rotate([a, 0, 0]).translate([0, 0, 26])`.

## 2. 겹침 재기
```python
import trimesh, numpy as np, manifold3d as m3
to_m = lambda tm: m3.Manifold(m3.Mesh(np.asarray(tm.vertices, np.float32), np.asarray(tm.faces, np.uint32)))
mate = to_m(trimesh.load("짝부품.stl"))
for a in range(-100, 61, 10):                     # 움직이는 범위 전체
    print(a, round((pose(mine, a) ^ mate).volume(), 1))
```
- 원본 부품으로 같은 검사를 먼저 돌려 기준값을 얻는다. 축이 구멍에 들어간 정도처럼 원래 있는 겹침이다.
- 내 부품은 모든 각도에서 기준값과 같아야 한다.
- 움직이는 범위는 원본이 끝에 닿는 각도까지로 잡는다. 원본 겹침이 갑자기 커지는 각도가 그 끝이다.

## 3. 닿는 곳 고치기
- 짝부품이 지나가는 자리를 내 부품에서 깎는다.
  - 짝부품을 내 부품 좌표로 옮겨 각도별로 합치면(sweep) 그 자리가 나온다.
  - 짝부품을 ±1 mm 옮긴 것까지 합치면 1 mm 여유가 생긴다.
- 원본에서 그대로 쓰는 부분(축, 다리, 걸쇠)은 깎지 않는다.
- 예: `불꽃과녁/build_reset_flame.py`의 `sweep`.

## 4. 원본 조건 다시 맞추기
- 무게로 돌아오는 부품(자동 복귀 과녁 등)은 축 기준 회전력(부피 x 무게중심까지 거리)을 원본 메시와 같게 맞춘다.
- 계산은 실제 메시에서 한다(`trimesh.volume`, `center_mass`).
- 크기는 배율을 이분법으로 바꿔 가며 맞춘다.

## 5. 눈으로 확인
- Blender MCP로 조립 자세 두세 개(서 있을 때, 끝까지 넘어갔을 때)를 불러온다.
- `look`의 angles로 앞, 뒤, 옆에서 본다.
- 색이 들어가는 부품은 앞뒤에서 색이 보이는지 같이 본다.

## 6. 출력 준비
- 출력 방향 STL로 서포트가 필요한 곳을 잰다(`overhang_regions.py`).
- 덩어리 수(`len(tm.split())`)와 닫힘(`is_watertight`)을 본다.
- 끼움 틈을 표로 정리한다.
- 슬라이스와 출력은 사용자가 요청할 때만 한다.
