# 탁구공 발사대 두 안 비교 (2026-11-10)

두 안 모두 같은 총신·공 통·15° 받침을 쓴다. MuJoCo 에서 같은 공과 공기 조건으로 쐈고, 기준은 불꽃 높이(0.07~0.20 m)에 맞는 로봇 거리를 약 1.16 m 로 맞춘 상태다.

## 구성
| | A 고무줄 + 서보 2개 | B 130 DC 모터 플라이휠 + 서보 1개 |
|---|---|---|
| 모델링 | build_launcher.py | build_flywheel.py |
| 쏘는 방식 | DS3218 레버로 플런저를 당기고, MG996R 걸쇠를 풀면 고무줄이 쏨 | MG996R 포크로 공을 밀어 넣으면, 돌고 있는 바퀴가 공을 천장에 눌러 굴려 쏨 |
| 살 것 | 없음(고무줄) | 130 모터 1개 |
| 서보 | DS3218, MG996R | MG996R |
| 전기 | 서보 신호 2개 | 서보 신호 + MOSFET(D4184) PWM 으로 모터 구동 + 모터 전원 |

| 쏘는 간격 | 약 1.5 s(당기기 0.6 + 걸쇠·레버 복귀) | 약 0.8 s, 다만 켜고 2 s 넘게 기다려야 바퀴가 다 돎 |
| 공 회전 | 거의 없음(1 rad/s) | 역회전 약 265 rad/s |
| 공 속도(같은 거리) | 4.4 m/s | 5.4 m/s(듀티 0.67, 5 V) |

## 판단 (2026-11-10 A 로 확정)
A 가 이 시연에 맞다.
- 공마다 다른 값(탄성)과 회전 양력에 거의 영향을 안 받는다. 고무줄 세기는 한 번 재서 맞추면 시연 중 바뀌지 않는다.
- B 는 공 탄성·고무 테 마모·공 회전 양력처럼 시연 중에도 바뀌는 값에 거리가 ±0.1 m 흔들린다. 맞는 구간 반폭(0.11 m)과 비슷하다.
- A 는 살 것이 없고, 모터 배선과 바퀴 회전 대기도 없다.
- B 가 나은 점: 빨리 연속으로 쏠 수 있고, 서보 1개, 저장 에너지·걸쇠가 없어 부딪힘 충격이 없다.

## 한계
- 고무줄 세기(80 N/m), 공 탄성(6 N/mm), 바퀴 마찰은 가정값이다. 실물 시험발로 보정한다.
- 레버·걸쇠·포크 서보는 시뮬에서 동작만 흉내 냈다(모양 충돌은 check_motion*.py 로 따로 점검).
- B 의 공-바퀴 미끄럼·눌림은 단단한 공 + 부드러운 접촉으로 근사해서, A 보다 시뮬 신뢰도가 낮다.
