## 조립 (핵심 세트만) — 순서 중요(검토에서 확인: 핀을 먼저 꽂으면 걸쇠가 안 들어감)
1. 플런저를 총신 뒤로 넣는다. 양옆 귀가 홈으로 들어간다. 플런저는 앞에 둔다.
2. 걸쇠: 총신과 레버 서보 벽 사이로 아래에서 올려 넣고(축 자리보다 40 mm 앞), 뒤로 밀어 축 자리에 맞춘다.
   - 걸쇠 구멍은 Ø5.5 드릴(또는 줄)로 한 번 다듬는다. 걸쇠가 제 무게로 툭 떨어질 만큼 헐거워야 한다(닫는 힘이 작음).
3. 걸쇠 핀: 몸통 구멍을 Ø5 드릴로 끝까지 한 번 뚫은 뒤(천장이 조금 처져 나옴), 벽 바깥에서 끝까지 눌러 꽂는다. 헐거우면 접착제.
4. 걸쇠 고무줄 1개(유니아트 4cm): 걸쇠 아래 갈고리 ↔ 총신 옆 기둥(x -55). 걸쇠가 뒤쪽 멈춤 턱에 앉아 있어야 한다.
5. 핀을 -y 쪽(레버 반대쪽)에서 꽂는다. 머리가 -y 쪽. 빡빡하면 플런저 핀 구멍을 Ø6.4 로 다듬는다.
6. 주 고무줄 2개: 핀 양쪽 홈 ↔ 총신 앞쪽 고리(x 12). (고무줄 없이 먼저 동작 확인을 권함)
7. 레버를 혼에 붙인다(밖에서).
   - 혼 구멍을 먼저 잰다. M3(지름 약 3)면 print_lever.stl 홈(폭 2.2)에 나사가 안 지나가므로 stl/print_lever_M3.stl(홈 폭 3.4)을 따로 뽑는다(약 6 g, 20분).
8. 서보(+혼+레버)를 벽의 U 홈에 위에서 내려 끼운다. 이때 레버는 장전 쪽 약 40° 여야 한다(20° 근처면 핀·플런저에 걸림). 서보에 전원을 넣어 각도를 만들고, 출력축을 손으로 돌리지 않는다. 바깥에서 플랜지 나사 4개(벽 구멍 Ø2.6, M3 셀프태핑 기준).

## 레버 쉼 각도 맞추기 (꼭, 고무줄 없이)
혼 톱니가 25개라 한 칸이 14.4° — 혼을 끼우면 레버가 최대 ±7.2° 어긋난다. 그대로 쓰면 발사가 안 되거나(덜 풀림) 레버가 몸통을 친다(-22° 넘으면 닿음).
1. 서보 라벨이 180° 판인지 본다(270° 판이면 각이 다 바뀐다).
2. 처음 전원은 천천히 한 각씩만 준다(한 번에 장전·발사 명령 금지). 어느 쪽이 장전 쪽(핀을 뒤로 미는 쪽)인지 먼저 본다.
3. 레버를 발사 쪽으로 천천히 돌려 손가락이 걸쇠 꼬리에 처음 닿는 서보 각 T 를 찾는다.
4. 쉼 = T + 3.5° (장전 쪽으로 3.5°), 장전 = 쉼 + 66~69°, 발사 = 쉼 − 18°.

## 서보 명령 (레버 서보 하나)
각도는 레버 쉼(0°) 기준이다. 쉼 = 서보 가운데(1500 µs)로 맞췄다고 놓는다.
- 장전 = 쉼에서 **장전 쪽 66°**, 발사 = 쉼에서 **반대쪽 18°**. 서보 방향은 고무줄 없이 먼저 천천히 돌려 확인한다(장전 쪽이 핀을 뒤로 미는 쪽).
- 발사 각을 -10° 보다 작게 주면 걸쇠가 덜 열린다(-10° 에서 겨우 풀림, -18° 에서 걸쇠 21° 열림, 풀리는 데 9° 필요).

한 발(15° 고정, 공 손으로)
1. 플런저가 앞에 있을 때 공 1개를 몸통 공 통에 넣는다(플런저 위에 얹힘).
2. 레버 → 장전 66°(빨리). 0.6 s 기다림. 공이 플런저 앞으로 떨어진다.
3. 레버 → 0° 를 초당 200° 이하로 천천히(0.33 s 이상). 0.1 s 기다림. 핀이 걸쇠에 걸려 선다.
4. 레버 → 발사 -18°. 공은 약 55 ms 뒤에 나간다.
5. 0.4 s 뒤 1로. 레버는 -18° 에서 바로 장전 66° 로 가도 된다.

## 실물에서 먼저 볼 것
1. 고무줄 없이: 레버를 손(또는 서보 천천히)으로 66° → 0° → -18° 돌려 걸쇠가 핀 뒤로 내려앉고 손가락이 걸쇠를 여는지.
2. 걸쇠 고무줄만 걸고: 걸쇠가 멈춤 턱에 붙어 있는지, 손으로 이빨을 눌렀다 놓으면 바로 돌아오는지.
3. 주 고무줄 걸고 공 없이 3번, 그다음 공 하나씩 3번.
4. 장전 66° 에서 핀이 -77 보다 뒤로 가는지(걸림면 -70.5 + 핀 반지름). 혼 끼움 1° 오차 ≈ 핀 1 mm.
5. 발사 각 -18° 에서 걸쇠가 확실히 풀리는지. 덜 풀리면 -22° 까지 늘려도 레버·걸쇠가 몸통에 안 닿는다.
