## 현재 확인한 기준선

Wego의 Ubuntu 22.04.5 / ROS 2 Humble에서 Webots·YOLO·MuJoCo를 실행했다.
지정 좌표 demo_candle 시연에서 정지 → MuJoCo 발사 → 접촉·직접 명중·전도 → 가상 소화 확인 → 주행 재개를 확인했다.
로그는 `contact=True, direct_hit=True, toppled=True; failure=success`였다.
현재 시연의 발사 초기 속도는 5.5 m/s이며 실제 장치의 실측 속도로 확정한 값이 아니다.
YOLO는 병행 실행했지만 이번 발사는 지정 좌표를 사용했다. YOLO 검출부터 발사까지의 성공, 전체 임무 완료, 실물 발사 성공을 뜻하지 않는다.

## 다음에 받을 정보

- 발사체 형상·치수·질량·재질, 가능하면 CAD/STL 또는 치수가 있는 사진.
- 발사 장치 장착 위치·높이, 발사구 원점과 방향, 상하·좌우 조준 범위.
- 발사 초기 속도(m/s), 발사 각도·높이, 반복 발사 시 속도·각도 편차.
- 속도를 직접 모르면 각도·높이별 비거리와 탄착점 측정 자료. 이 경우 초기 속도 추정값과 직접 측정값을 구분한다.

## 다음 세션 작업 순서

1. 사용자가 제공한 형상·측정 자료를 확인하고 단위·좌표계·실측값과 잠정값을 구분한다.
2. 실제 형상과 발사 원점·조준 범위를 MuJoCo 모델에 반영한다.
3. 발사 속도·각도·질량·크기를 적용하고, 자료가 있으면 속도·각도 편차도 반영한다.
4. 실제 탄착점에 맞춰 보정하고, 보정에 쓰지 않은 측정 자료로 검증한다.
5. 기존 5.5 m/s 기준선과 비교해 탄착 오차·직접 명중·전도를 각각 기록한다. 허용 오차와 반복 횟수는 자료 확인 후 시험 전에 정한다.

공기저항·회전 효과는 현재 입력값 조정만으로 적용된다고 가정하지 않는다. 필요성이 확인되면 별도 모델 구현 범위로 정한다.
